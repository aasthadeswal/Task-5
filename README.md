# Titanic Dataset - Exploratory Data Analysis (EDA)

This repository contains a detailed Exploratory Data Analysis (EDA) project on the Titanic dataset using Python. The objective is to extract meaningful insights using both statistical and visual techniques to understand patterns, trends, and anomalies in the dataset.

---

## 🎯 Objective

To explore and analyze the Titanic dataset to:

- Understand survival patterns across different passenger categories
- Visualize key trends and relationships in the data
- Perform statistical summary and generate insights
- Practice and demonstrate data storytelling using Python

---

## 🛠 Tools Used

- Python  
  - Pandas (data manipulation)  
  - Matplotlib & Seaborn (data visualization)
- Jupyter Notebook  
- Titanic dataset (public dataset from Kaggle or equivalent)

---

## 📊 Key Features

- **Summary Statistics**: Used `.describe()`, `.info()`, `.value_counts()` to get basic statistics  
- **Visual Analysis**:  
  - `sns.heatmap()` to detect correlations  
  - `sns.pairplot()` for pairwise relationships  
  - Histograms, Boxplots, and Scatterplots for distributions and relationships  
- **Trend & Relationship Analysis**: Gender vs. survival, Class vs. survival, Age distribution, etc.  
- **Insightful Observations**: Key takeaways added under each visual  
- **Summary of Findings**: Final section with overall insights

---

## 💡 Key Insights

- Higher survival rate observed in females and upper-class passengers  
- Children had a higher chance of survival compared to adults  
- Passengers in 3rd class had the lowest survival rate  
- Fare and class are strongly correlated with survival chances  
- Missing values in age and cabin required handling (e.g., imputation or exclusion)
